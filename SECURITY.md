# Security policy

## Supported versions

beau is pre-1.0. Security fixes land on the latest `0.x` release only.

| Version | Supported |
| ------- | --------- |
| latest `0.x` | Yes |
| older | No |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/ibra/beau/security/advisories/new)).

Include a description, the affected version, and steps or a minimal example
to reproduce. You can expect an acknowledgement within a few days. Once a fix
is ready, it is released and an advisory is published crediting the reporter
(unless you prefer otherwise).
